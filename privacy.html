Privacy Policy

This policy explains what ReSpeedPost accesses, where processing occurs, what is transmitted, and how users can revoke access or delete local data.

Product scope

ReSpeedPost is a desktop and command-line application that lets users select creator-owned local videos, optionally adjust playback speed, preview and edit publishing choices, and explicitly authorize publication to their TikTok account.

Information accessed from TikTok

After authorization, ReSpeedPost uses TikTok's APIs to retrieve the connected creator's username, nickname, currently available privacy levels, comment, Duet and Stitch restrictions, and maximum supported video duration. The application uses the user.info.basic and video.publish scopes. It does not request messages, contacts, passwords, advertising profiles, or unrelated account data.

Local video processing

Selected videos and re-speeded outputs are processed on the user's computer. ReSpeedPost does not send video files to its OAuth service.

Publishing transfer

After the user reviews the creator identity, video, caption, visibility, interaction settings, cover frame, and final confirmation, the selected local file is uploaded directly from the user's device to TikTok's Content Posting API. TikTok processes that transfer under its own privacy policy and terms.

OAuth service

ReSpeedPost uses a small hosted service solely to keep the TikTok client secret out of the distributed desktop application. The service exchanges a short-lived authorization code for TikTok tokens and refreshes tokens when requested. It does not receive video files, captions, publishing settings, or local file paths. Requests and basic operational logs may be processed temporarily by the hosting provider for security and reliability.

Information stored locally

The desktop application stores configuration and TikTok access and refresh tokens under %APPDATA%\ReSpeedPost. Processed video outputs are stored in the user-selected or configured output directory. ReSpeedPost does not sell data, create advertising profiles, or use account data for unrelated analytics.

Retention and deletion

Local configuration, tokens, and outputs remain until the user deletes them. Users can delete local authorization data by removing %APPDATA%\ReSpeedPost\tiktok_token.json. Processed videos can be removed from the output directory using normal operating-system file controls.

Revoking TikTok access

Users can revoke ReSpeedPost through TikTok's connected-app permissions under TikTok Settings and privacy, Security and permissions, Apps and services permissions. Revocation prevents future API access but does not remove content already published; existing posts must be managed in TikTok.

Security

OAuth uses state validation and PKCE. Tokens are stored locally and are not committed to the public source repository. The client secret remains in the hosted OAuth service. Users must protect access to their computer and should never include tokens, OAuth codes, or private media in issue reports.

Third-party services

Use of TikTok is subject to the TikTok Privacy Policy and applicable TikTok terms. The OAuth service's infrastructure provider may process limited request metadata required to operate and secure the service.

Changes

Material changes will be published on this page with an updated effective date.

Contact

Privacy questions can be submitted through the ReSpeedPost issue tracker. Do not post private account data or credentials publicly.
