Documentation

Install, process, connect, publish.

Reference documentation for the ReSpeedPost desktop application and command-line interface.

System requirements

  • Windows 10 or newer.
  • Python 3.11 or newer for source installations.
  • FFmpeg and FFprobe available on PATH.
  • A TikTok account and network access for account connection and publishing.

Install from source

git clone https://github.com/ratagrande/re-speed-post-app
cd re-speed-post-app
py -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
respeedpost-gui

Local processing

Select a video and choose a speed from 0.25× to 4.00×. ReSpeedPost prepares compatible H.264/AAC media locally and never overwrites the selected source.

Connect a TikTok account

  1. Open ReSpeedPost and select Connect TikTok.
  2. Review TikTok's authorization screen in the browser.
  3. Approve only the displayed scopes.
  4. Return to ReSpeedPost and refresh the connected creator.

The app requests user.info.basic to show the destination creator and video.publish to publish an explicitly confirmed post.

Publish from the desktop interface

  1. Preview the selected video.
  2. Choose speed and cover-frame time.
  3. Refresh creator settings.
  4. Edit the caption, visibility, comments, Duet, and Stitch choices.
  5. Select Review and publish.
  6. Verify the final creator, file, speed, visibility, and caption, then confirm.

Command line

Process only

respeedpost process clip.mp4 --speed 1.25 --output output

Process and publish

respeedpost publish clip.mp4 --speed 1.15 \
  --caption "Creator-approved caption" \
  --privacy SELF_ONLY --confirm

The CLI retrieves current creator choices before publishing. Without --confirm, it prints a complete summary and requires the user to type YES.

Files stored locally

Configuration, TikTok tokens, and processed outputs are stored under %APPDATA%\ReSpeedPost. See the Privacy Policy for retention and deletion instructions.
