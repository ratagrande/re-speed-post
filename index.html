Desktop application

Prepare and publish from Windows.

ReSpeedPost for Windows processes video locally, connects through TikTok Login Kit, displays the authorized creator and current publishing choices, and sends a post only after final confirmation.

Download for WindowsInstallation guideRelease notes

The self-contained ZIP includes FFmpeg 9.0.1 and FFprobe. No Python or separate multimedia installation is required.

FFmpeg is included under GPLv3. Its corresponding source, license, and build information are available with the release.

Complete workflow

Every publishing decision remains visible.

The desktop app separates selecting, processing, reviewing, and publishing so choosing a file never starts an upload.

1

Local video processing

Choose a speed from 0.25× to 4.00×. Bundled FFmpeg prepares a compatible H.264/AAC file on the user's computer.

2

Preview and timing

Review the selected video and cover-frame position before any transfer begins.

3

Authorized account

Login Kit connects a TikTok account, and ReSpeedPost displays the returned creator identity.

4

Current creator choices

The app retrieves TikTok-provided privacy levels, interaction restrictions, and maximum duration.

5

Editable post details

Edit the description, hashtags, visibility, comments, Duet, Stitch, and cover frame.

6

Explicit confirmation

A final summary identifies the creator, video, speed, visibility, and description before publishing.

Privacy by design

Local until you choose to publish.

The browser preview never uploads a file. In the desktop app, processing remains local and video bytes are transferred directly to TikTok only after the user reviews and confirms the post.
